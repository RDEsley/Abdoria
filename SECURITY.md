# Política de segurança

## Versões suportadas

O Evolyn está em desenvolvimento contínuo. Correções de segurança são aplicadas apenas à versão
publicada na branch `main`.

## Como reportar

Não abra uma issue pública para vulnerabilidades, credenciais expostas ou formas de acessar dados
de outros usuários. Use o recurso **Report a vulnerability** na aba Security do repositório.

Inclua, quando possível:

- impacto observado;
- passos mínimos para reproduzir;
- ambiente afetado;
- sugestão de mitigação.

Não inclua tokens, senhas, chaves do Supabase/Vercel ou dados pessoais reais no relatório.
